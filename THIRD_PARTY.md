# GitHub Readme Streak Stats

The streak cards use [DenverCoder1/github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats)
at commit `adbd07609bb771d3510a15ee2f3b31d5fbe5201d` (v1.8.1). The Action
generates the original SVG locally. `streak.py` preserves the statistics and
ring/flame artwork while changing typography, themes and the mobile layout.
`fixtures/streak-upstream.svg` records its output structure for offline tests.
